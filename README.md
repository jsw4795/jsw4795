## 대표 프로젝트

### [Cabbage Market](https://github.com/jsw4795/Cabbage_Market) — 중고거래 서비스

**6인 팀 프로젝트 · 담당: 채팅 기능, 팀원 코드 통합**

`Java` `Spring MVC` `MyBatis` `Oracle` `SSE`

- **통신 방식 분리** — 메시지 전송은 기존 요청/응답 흐름인 HTTP/AJAX로 처리하고, 상대방에게 새 메시지·읽음 상태를 알리는 서버 이벤트는 SSE로 전달했습니다. 현재 구현은 서버→클라이언트 전달에 집중되어 있어, 양방향 연결을 별도로 유지하지 않는 구조입니다.
- **연결 단절 대응** — SSE가 다시 연결되어도 끊긴 사이의 이벤트는 누락될 수 있어, 이벤트 ID와 5분 TTL의 최근 이벤트 캐시를 두었습니다. `Last-Event-ID` 이후 캐시에 남은 이벤트를 재전송합니다. 메모리 캐시이므로 서버 재시작 또는 TTL 만료 이후까지 복구하지는 않습니다.
- **업로드 경로 분리** — 프로젝트 내부 리소스에 저장한 사진이 늦게 반영되던 문제를 확인해, 사용자 업로드 파일을 프로젝트 외부 경로로 분리하고 URL Context 매핑으로 접근하게 했습니다. 배포 리소스와 런타임 생성 파일을 분리한 대신 저장 경로와 서버 매핑을 함께 관리해야 합니다.
